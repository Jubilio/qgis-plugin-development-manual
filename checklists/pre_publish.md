# Pre-publication checklist

- [ ] Plugin loads and unloads without traceback.
- [ ] Metadata, VERSION and changelog are synchronised.
- [ ] Homepage, repository and tracker links work.
- [ ] English description and detailed About field are present.
- [ ] Licence is included in the plugin folder.
- [ ] External dependencies are documented.
- [ ] QGIS 3/4 and Qt 5/6 commitments are tested.
- [ ] No direct PyQt5/PyQt6 imports.
- [ ] No binaries, secrets, caches or hidden directories.
- [ ] ZIP contains one plugin folder at the top level.
- [ ] Source matches the tagged repository commit.
- [ ] Sample data contains no confidential information.
